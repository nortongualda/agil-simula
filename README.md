# Ágil Simula

Estudos de viabilidade de importação da Ágil Aduaneira: custos reais da operação (tributos, despesas locais e rateio por item), histórico de versões e exportação em PDF e Excel.

- Login e dados no Supabase (projeto agil-desk, tabelas `simula_acesso` e `simula_docs`).
- Cada estudo pertence ao login que o criou; usuários master veem todos.
- Proformas em Excel/CSV são lidas no navegador (`js/planilha.js`).
